# Contributing

Pull requests are welcome! If you'd like to add a resource:

- Make sure it is directly about glTF/GLB (or a glTF-based format like VRM), not general 3D tooling.
- Add it to the matching section using the format `- [Name](url) - Short description.`
- Keep the description to one line, in English, ending with a period.

If you're not sure where something fits, open an issue first.
